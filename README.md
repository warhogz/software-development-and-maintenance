# Области и районы — JavaFX, MVC

Дисциплина «Разработка и сопровождение программных систем».
Лабораторные работы 1.4–1.6, вариант 13 (предметная область «Области – Районы»).

Выполнил: Хасаев Умахан, группа ИСТ-331.

| Папка | Содержание |
|---|---|
| `lab1_4` | ЛР 1.4. Создание компонентов MVC: классы-модели, ObservableList, TableView и контроллер |
| `lab1_5` | ЛР 1.5. Взаимодействие с пользователем: выбор в таблице, кнопки «Новый / Изменить / Удалить», диалоговое окно, проверка ввода |
| `lab1_6` | ЛР 1.6. Стилизация представлений с помощью CSS: тёмная тема `RegionTheme.css`, иконка приложения |
| `reports` | Отчёты по лабораторным работам |
| `screenshots` | Скриншоты работы приложения |

## Запуск

Открыть папку нужной лабораторной работы в IntelliJ IDEA как Maven-проект и запустить класс `ru.lab.regionapp.MainApp`
(или выполнить `mvn javafx:run`). Используется JDK 21+ и JavaFX 21.
