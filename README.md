# Области и районы — JavaFX, MVC

Лабораторные работы 1.4 и 1.5, вариант 13 (предметная область «Области – Районы»).

Выполнил: Хасаев Умахан, группа ИСТ-321.

| Папка | Содержание |
|---|---|
| `lab1_4` | ЛР 1.4. Создание компонентов MVC: классы-модели, ObservableList, TableView и контроллер |
| `lab1_5` | ЛР 1.5. Взаимодействие с пользователем: выбор в таблице, кнопки «Новый / Изменить / Удалить», диалоговое окно, проверка ввода |
| `reports` | Отчёты по лабораторным работам |
| `screenshots` | Скриншоты работы приложения |

## Запуск

Открыть папку `lab1_4` или `lab1_5` в IntelliJ IDEA как Maven-проект и запустить класс `ru.lab.regionapp.MainApp`
(или выполнить `mvn javafx:run`). Используется JDK 21+ и JavaFX 21.
