# Лабораторная работа 1.9

Веб-приложение `persons` демонстрирует подключение Bootstrap и jQuery, а также использование общих JSP-фрагментов `header.jsp` и `footer.jsp`.

## Запуск

1. Импортировать папку `lab1_9` в Eclipse как Maven-проект.
2. Добавить проект на Apache Tomcat 10.
3. Открыть `http://localhost:8080/persons/`.

Для быстрой визуальной проверки без сервера можно открыть `src/main/webapp/preview.html`.
